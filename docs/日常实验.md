# 日常实验

源码在 StudyLab/projects/ysyx/Main，由 Windows 编辑和管理 Git；编译、仿真和调试通过 StudyLab 的 WSL 隔离入口完成。

## 进入终端

在 Workspace 根目录：

```powershell
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project ysyx
```

在 WSL 终端：

```bash
bash /mnt/e/Workspace/Tools/wsl-sandbox/run.sh --project ysyx shell
```

进入后位于 /workspace/Main，NEMU_HOME、AM_HOME、NPC_HOME、NVBOARD_HOME 等仅由本项目注入。直接运行 cd nemu、make、make run、make menuconfig、make gdb。Ctrl+C 中断前台程序，exit 退出会话。单会话含等待输入最多 30 分钟。

## 图形与下载

NVBoard 与 GTKWave 使用 -Gui，依赖下载使用 -Network。对应 WSL 选项为 --gui、--network。两项都必须由项目描述声明，再显式启用。

```powershell
& .\Tools\wsl-sandbox\sandbox.ps1 -Action Shell -Project ysyx -Gui
```

NVBoard 示例在终端内 cd nvboard/example 后 make run。不要在普通 WSL 或 Windows 中直接运行大波形和项目程序。

## Git、日志与恢复

官方 tracer-ysyx 分支继续由 Makefile 自动记录，日常 Git 在 Windows 的 Main 目录进行；不删除追踪历史。文本使用 UTF-8、LF。第三方代码保留上游格式。

当前批量日志在平台 logs/ysyx/，交互只登记会话元数据；迁移前的原始证据保留在项目 logs/。完整环境、挂载、资源限制和验证见 [平台开发环境](../../../../docs/开发环境.md)。NEMU 首次运行只覆盖内置四指令镜像，详细历史见 [开发环境](开发环境.md)。
